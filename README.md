# 🦾 减肥大作战

一个趣味减肥游戏，让减肥变得好玩！

## 🎮 游戏特性

### 核心玩法
- **创建角色** - 录入你的体重信息
- **锻炼动作** - 完成各种锻炼消耗卡路里
- **体重变化** - 实时显示体重增减
- **抽卡系统** - 抽取"绝对特性"卡牌获得特殊效果

## 🚀 如何开始游戏

### 方法 1：手机直接访问（推荐）
1. 确保你的手机和电脑在同一 WiFi 网络
2. 在电脑终端运行：
   ```bash
   cd /home/admin/.openclaw/workspace/fitness-game
   python3 -m http.server 8080
   ```
3. 查看电脑的 IP 地址：
   ```bash
   ifconfig | grep "inet "
   ```
4. 在手机浏览器访问：`http://<你的电脑IP>:8080`

### 方法 2：本地浏览器测试
直接在电脑浏览器打开 `index.html` 文件

### 方法 3：部署到服务器
将文件上传到任何 Web 服务器即可访问

## 📱 游戏规则

1. **每日目标**：消耗 500 kcal
2. **不锻炼惩罚**：每天不锻炼自动增重 0.3kg
3. **抽卡限制**：每天只能抽一次卡
4. **体重计算**：约 7700 kcal = 1 kg

## 💾 数据存储

所有数据保存在浏览器 localStorage 中：
- 角色信息
- 体重记录
- 锻炼历史
- 卡牌收藏

## 🛠️ 自定义

### 添加新动作
编辑 `app.js`，在 `exercises` 或 `crazyExercises` 数组中添加：
```javascript
{ id: 9, name: '新动作', icon: '🎯', calories: 100, duration: 60 }
```

### 添加新卡牌
编辑 `app.js`，在 `cardDeck` 数组中添加：
```javascript
{ 
    name: '新卡牌', 
    desc: '效果描述', 
    effect: { type: '自定义类型', value: 数值 } 
}
```
